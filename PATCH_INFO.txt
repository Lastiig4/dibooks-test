DiBooks Patch - Reader Feedback V1
==================================

DOEL
Variable-effect wijzigingen kunnen nu optioneel een zichtbare melding aan de
lezer geven.

BELANGRIJK
Reader feedback is ALTIJD opt-in per effect.
Geheime flags/variabelen blijven dus onzichtbaar zolang
'Reader feedback' uit staat.

ONDERSTEUND OP
- Keuze effects
- Minigame success effects
- Minigame fail effects
- Function node actions
- Studio Preview
- Publieke Reader

READER FEEDBACK TYPES
- 🎒 Item ontvangen
- 🗑️ Item verloren
- ❤️ Relatie verbeterd
- 💔 Relatie verslechterd
- ⬆️ Stat omhoog
- ⬇️ Stat omlaag
- ℹ️ Eigen / algemene melding

PER EFFECT
In de Studio staat nu:
Reader feedback [aan/uit]

Wanneer aan:
1. kies type;
2. optioneel eigen tekst, bijv.
   'Mattias vertrouwt je meer.'

Als eigen tekst leeg blijft gebruikt DiBooks de naam van de variabele als
fallback.

VOORBEELD
Keuze:
'Vertel Mattias de waarheid'

Effect 1:
mattias_relation +2
Reader feedback:
❤️ Relatie verbeterd
'Mattias vertrouwt je meer.'

Effect 2:
mattias_knows_secret = true
Reader feedback UIT

De lezer ziet dan alleen de relatie-update en niet de geheime flag.

TOASTS
- verschijnen rechtsboven;
- verdwijnen automatisch na ongeveer 3,6 seconden;
- meerdere zichtbare effecten worden onder elkaar gezet.

TERUGLEESMODUS
Reader feedback wordt NIET opnieuw uitgevoerd of getoond tijdens
Terugleesmodus.

De bestaande read-only history/story-state bescherming blijft intact.

FUNCTION NODES
Function nodes blijven onzichtbaar.
Als een function-action Reader feedback aan heeft, verschijnt de toast pas
nadat de function state/progress succesvol is opgeslagen en de route doorgaat.

STUDIO PREVIEW
Dezelfde toast verschijnt ook in Preview, zodat auteurs het resultaat direct
kunnen testen.

OPSLAG / COMPATIBILITEIT
De feedbackvelden worden in de bestaande project JSON opgeslagen als onderdeel
van een FunctionAction:
- notifyReader
- notificationType
- notificationText

Oude boeken blijven volledig werken omdat alle velden optioneel zijn.

GEEN SQL NODIG.

INSTALLEREN
1. ZIP uitpakken.
2. Sleep map `app` over `dibooks_author_studio`.
3. Bestanden vervangen.
4. npm run build.
5. Commit/push naar Vercel.

TEST
1. Maak getalvariabele `mattias_relation`.
2. Geef keuze effect `+1`.
3. Zet Reader feedback aan.
4. Kies ❤️ Relatie verbeterd.
5. Tekst: `Mattias vertrouwt je meer.`
6. Preview -> maak keuze.
7. Controleer toast.
8. Public/test Reader -> controleer toast.
9. Blader terug -> toast mag NIET opnieuw verschijnen.
10. Test daarnaast een geheime flag met Reader feedback UIT.

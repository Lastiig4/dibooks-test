DiBooks Patch - Schone cover op boekpagina
=========================================

Wat verandert:
- Titel-overlay onderaan de cover verwijderd.
- 'Interactive story' op de cover verwijderd.
- Grote boektitel links blijft staan.
- Genre/status badges bovenaan de cover blijven staan.
- Donkere cover-overlay is subtieler gemaakt zodat artwork beter zichtbaar blijft.
- Overige boekpagina-functionaliteit is ongemoeid gelaten.

Installeren:
1. Pak de ZIP uit.
2. Sleep de map 'app' over de hoofdmap van dibooks_author_studio.
3. Kies 'Bestanden vervangen' als Windows daarom vraagt.
4. Start/herstart met: npm run dev

Verwacht pad:
app/books/[bookId]/page.tsx

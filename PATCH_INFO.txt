DiBooks Patch - Editor Demo Polish V1
====================================

Deze patch bouwt voort op Public Studio Trial V1.

WAT VERANDERT

1. Zichtbare proefmodus-teller
Niet-Auteur gebruikers zien bovenin de Studio een rustige teller:

  Proefmodus  7/15

Er is GEEN extra melding of waarschuwing wanneer iemand bijna op 15 zit.

Function, IF, Hoofdstuk-marker en Kladblok tellen zoals eerder NIET mee.

2. Auteur worden
Naast de teller staat:

  Auteur worden

Gast:
- opent direct Registreren met het Auteur-plan geselecteerd.

Ingelogde Gratis/Reader gebruiker:
- opent het plan-overzicht in een nieuwe tab;
- de editor blijft dus open en de sessiesave blijft staan.

3. Limiet
Bij 15/15 blijft de bestaande harde blokkade werken.
Pas wanneer iemand daadwerkelijk node 16 probeert toe te voegen krijgt
hij een korte melding dat het Auteur-plan onbeperkt bouwen mogelijk maakt.

Er bestaat dus GEEN 'je bent bijna vol'-waarschuwing.

4. Bestaande trial-regels blijven intact
Zonder Auteur-plan:
- maximaal 15 echte verhaalnodes;
- lokaal opslaan/laden blijft mogelijk;
- Play/Preview blijft mogelijk;
- geen Dashboard-opslag;
- geen publicatie/review;
- geen online author-writes.

Met Auteur-plan/Admin:
- onbeperkt;
- Dashboard;
- publicatieflow;
- volledige Studio.

GEEN SQL NODIG.
Public Studio Trial V1 SQL hoeft niet opnieuw uitgevoerd te worden.

INSTALLEREN
1. ZIP uitpakken.
2. Sleep alleen map 'app' over dibooks_author_studio.
3. Bestanden vervangen.
4. npm run build.
5. Commit/push naar GitHub/Vercel.

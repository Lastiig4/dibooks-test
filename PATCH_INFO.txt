DiBooks Patch - Moderation Review Modal V4
==========================================

GEBRUIK DEZE V4 IN PLAATS VAN V3.
Je gaf aan dat je V3 nog niet had geïnstalleerd. V4 bevat daarom OOK alle V3-
wijzigingen (snelle akkoordknoppen + één algemene motivatie bij high flags).

NIEUW: GROTE CENTRALE REVIEWINSPECTIE
- Klik in reviewmodus op een node -> grote popup midden in beeld.
- Klik op een rode/oranje melding -> kaart centreert op de node EN popup opent.
- Links in popup: alle meldingen van die node.
- Rechts: volledige node-inhoud.
- Lange teksten krijgen veel meer leesruimte dan in de smalle rechterbalk.
- Oranje en rode waarschuwingen blijven met één klik afhandelbaar.
- Afgehandelde flags kunnen worden heropend.
- 'Volgende open melding' zit ook in de popup.
- De oude rechterbalk is nu alleen een compacte samenvatting + knop om de grote
  inspectie te openen.

NIEUW: ADMINNAAM IN BOEKMODERATIE

INSTALLEREN
1. Supabase -> SQL Editor -> New query.
2. Voer MODERATION_REVIEW_MODAL_V4_SUPABASE.sql uit.
   Deze bevat de benodigde V3 + V4 SQL.
3. Pak ZIP uit.
4. Sleep over dibooks_author_studio:
   - app
   - lib
   - supabase
5. Kies Bestanden vervangen.
6. npm run build
7. Commit/push.

Geen wijziging nodig aan DEEPSEEK_API_KEY.

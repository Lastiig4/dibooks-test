DiBooks Patch - DeepSeek Node Moderation
========================================

Deze patch VERVANGT alleen de automatische OpenAI-scanner door DeepSeek.
Moderation Core zelf blijft hetzelfde.

Provider:
- DeepSeek API
- model: deepseek-v4-flash
- thinking: disabled
- JSON Output

Waarom Flash:
- snel
- goedkoop
- ruim voldoende voor eerste inhoudelijke triage
- admin blijft altijd degene die beslist

WAT BLIJFT HETZELFDE
- Auteur dient boek in.
- Review-snapshot wordt bevroren.
- Admin krijgt melding.
- Boekmoderatie-pagina blijft bestaan.
- Revieweditor blijft read-only.
- Verdachte nodes krijgen ⚠.
- Admin accepteert of wijst af met feedback.
- AI kan NOOIT zelfstandig afwijzen.

INSTALLEREN

1. Supabase -> SQL Editor -> New query.
2. Voer DEEPSEEK_NODE_MODERATION_SUPABASE.sql uit.

   Dit verwijdert geen handmatige adminflags.
   Bij een nieuwe scan worden alleen oude automatische OpenAI/DeepSeek-flags
   van dezelfde inzending vervangen.

3. Pak de ZIP uit.
4. Sleep de map 'app' en 'supabase' over dibooks_author_studio.
5. Kies Bestanden vervangen.

6. Zet lokaal in .env.local:

   DEEPSEEK_API_KEY=jouw_deepseek_key

7. Zet in Vercel:
   Project -> Settings -> Environment Variables

   Key:
   DEEPSEEK_API_KEY

   Value:
   alleen jouw DeepSeek API key

   Sensitive: aan
   Environments: Production and Preview

8. Redeploy.

Je bestaande OPENAI_API_KEY mag uit Vercel worden verwijderd als DiBooks hem
nergens anders gebruikt. Hij wordt door deze scanner niet meer aangeroepen.

TEST
- Open een pending boek als admin.
- Klik 'AI opnieuw scannen'.
- Na de scan moet je een melding krijgen met aantal flags.
- Open de reviewmodus.
- Gemarkeerde nodes krijgen de bestaande ⚠.

De scanner beoordeelt context:
een normaal fantasygevecht hoort niet automatisch als probleem gemarkeerd te
worden. Expliciete/grafische, haatdragende, seksuele, uitbuitende, gevaarlijk
instructieve of leeftijdsgevoelige passages worden eerder voor menselijke
controle gemarkeerd.

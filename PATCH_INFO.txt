DiBooks Patch - Account & Security V1
=====================================

BELANGRIJK
Voer EERST uit:
ACCOUNT_SECURITY_V1_SUPABASE.sql

Daarna de mappen `app`, `components` en `lib` vervangen.

NIEUW

1. Naam en auteursnaam apart
Account > Profielgegevens:
- Naam
- Auteursnaam
- E-mailadres

Auteursnaam wordt de standaard auteur voor NIEUWE boeken.
Bestaande boeken worden bewust NIET automatisch hernoemd.

Bij bestaande accounts vult de SQL auteursnaam initieel met de huidige
display_name.

2. Profiel bewerken
Naam + auteursnaam kunnen vanuit Account worden opgeslagen.

De auth-cache wordt direct bijgewerkt zodat de nieuwe naam zonder uitloggen
zichtbaar wordt.

3. E-mailadres wijzigen
Account bevat nu 'E-mail wijzigen'.

Supabase Auth beheert de wijziging. Afhankelijk van je Supabase Auth-instellingen
kan eerst een bevestigingsmail nodig zijn.

4. Wachtwoord wijzigen
Onder Beveiliging:
- Nieuw wachtwoord
- Herhaal nieuw wachtwoord
- Wachtwoord wijzigen
- Resetmail sturen

5. Wachtwoord vergeten bij Login
De loginmodal heeft nu:
'Wachtwoord vergeten?'

Dit verstuurt een Supabase resetmail naar het ingevulde e-mailadres.
De recovery-link keert terug naar:
/account?recovery=1

Account toont dan direct dat de gebruiker een nieuw wachtwoord kan kiezen.

LET OP VOOR SUPABASE AUTH
In Supabase Dashboard > Authentication > URL Configuration moet je productie-
domein toegestaan zijn als Redirect URL, bijvoorbeeld:
https://www.dibooks.nl/account
of passend wildcardbeleid voor je deployment.

6. Abonnement rustiger zichtbaar
Account heeft nu één compacte Abonnement-kaart:
- huidig plan;
- rol;
- Plannen bekijken;
- Auteur Dashboard / Studio.

Billing is nog NIET gekoppeld.

7. Royalty & uitbetalingen voorbereid
Er staat een rustige placeholder onder Abonnement voor:
- definitieve royalty-overzichten;
- uitbetaalbaar saldo;
- uitbetalingsmethode.

Er wordt in deze V1 nog GEEN geld berekend of opgeslagen.

8. Auteursnaam automatisch bij nieuwe boeken
Auteur Dashboard + Studio gebruiken voortaan:
authorName -> fallback display name

Daardoor hoeft een auteur zijn pseudoniem niet bij elk nieuw boek opnieuw
in te vullen.

INSTALLEREN
1. ZIP uitpakken.
2. ACCOUNT_SECURITY_V1_SUPABASE.sql uitvoeren in Supabase SQL Editor.
3. `app`, `components`, `lib` over je project slepen en vervangen.
4. npm run build.
5. Commit/push naar Vercel.

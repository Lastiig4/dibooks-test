DiBooks Patch - Book Access & Royalty Copy V1
==============================================

WAT VERANDERT

De bestaande Toegang-keuze blijft technisch exact hetzelfde:
- accessType = free
- accessType = premium

Alleen de auteurs-UX wordt duidelijker.

GRATIS
Dropdown:
Gratis leesbaar — geen royalty

Uitleg:
Iedereen kan het boek lezen.
Gratis leestijd bouwt geen royalty op.
Geschikt als demo, proloog of instapdeel van een serie.

READER
Dropdown:
Reader / abonnement — royalty

Uitleg:
Alleen Reader Plus, Author Pro of Admin kan lezen.
Geverifieerde leestijd telt mee voor de maandelijkse auteursroyalty’s
zodra het royaltysysteem actief is.

AANGEPAST OP BEIDE PLEKKEN
- Nieuw / wijzigen boek in Auteur Dashboard
- Opslaan / metadata vanuit Auteur Studio

BELANGRIJK
Deze patch verandert nog GEEN financiële berekeningen.
Hij legt alleen de toekomstige royaltybetekenis correct vast in de UI.
Het echte royalty-ledger, maandafsluiting en payouts bouwen we later.

GEEN SQL NODIG.

INSTALLEREN
1. ZIP uitpakken.
2. Sleep de map app over dibooks_author_studio.
3. Bestanden vervangen.
4. npm run build.
5. Commit/push naar GitHub/Vercel.

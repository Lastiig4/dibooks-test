DiBooks Patch - Afbeelding Node V1
================================

NIEUW
Media & interactie > Afbeelding

Gebruik voor wereldkaarten, plattegronden, brieven, dossiers, illustraties of andere stilstaande beelden.

EDITOR
- Nieuwe blauwe Afbeelding-node.
- Upload PNG/JPG/WEBP/GIF.
- Maximaal 5 MB per afbeelding in V1.
- Optionele alt-tekst.
- Optioneel onderschrift.
- Node is pas compleet als een afbeelding is toegevoegd.
- Editor Lock en Undo werken ook met deze node.

STUDIO PREVIEW
Afbeeldingen verschijnen op een eigen scherm, met behoud van aspect ratio.
Bij één path verschijnt Verder; bij meerdere paths verschijnen routeknoppen.

PUBLIEKE READER
- Eigen afbeelding-scherm.
- Responsive op desktop/tablet/mobiel.
- Optioneel onderschrift.
- Ondersteunt normale paths.
- Ondersteunt Terugleesmodus.
- Telt als één zichtbare verhaalstap in de globale voortgang.

OPSLAG V1
De afbeelding wordt als data-URL in de bestaande project JSON opgeslagen.
Daarom is geen SQL of nieuwe storage-bucket nodig.

Voor een latere V2 kunnen we grote afbeeldingen naar DiBooks Storage verplaatsen, net zoals cutscenes, zodat projecten kleiner blijven.

BEHOUDEN
- Reader Feedback FIFO queue
- Editor Lock + Undo
- Scene Info
- Global Reader Progress
- Terugleesmodus
- Function/IF/variables
- Tab-focus stability

GEEN SQL NODIG.

INSTALLEREN
1. ZIP uitpakken.
2. Sleep map app over dibooks_author_studio.
3. Bestanden vervangen.
4. npm run build.
5. Push/deploy.

TEST

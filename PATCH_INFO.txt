DiBooks Patch - Editor Safety + Scene Info V1
=============================================

SCÈNE-INFO
Leeg betekent nu echt leeg.

Voor nieuwe Tekst/Speciale nodes:
- ingevuld: toon info zolang die node actief is;
- leeg: toon niets extra's zolang die node actief is.

Voorbeeld:
Node A = Cycle 64 • Day 83
Node B = leeg
Node C = Cycle 64 • Day 84

Reader:
A -> Hoofdstuk ... • Cycle 64 • Day 83
B -> alleen Hoofdstuk ...
C -> Hoofdstuk ... • Cycle 64 • Day 84

Als de context verandert, ook van ingevuld naar leeg, begint de volgende
context op een nieuwe reader-pagina.

Alleen OUDE nodes zonder sceneInfo-property gebruiken nog het oude
Hoofdstukinfo/chapterSubtitle als backwards-compatible fallback.

EDITOR LOCK
Nieuw slotje links onderaan.

Vergrendeld:
- nodes niet verslepen;
- geen node/edge wijzigingen via ReactFlow;
- rechter instellingenpaneel geblokkeerd;
- nieuwe nodes toevoegen geblokkeerd;
- variabelen openen geblokkeerd;
- lokaal project laden geblokkeerd;
- Reset editor geblokkeerd.

Nog wel mogelijk:
- selecteren/kijken;
- pan/zoom;
- Preview;
- opslaan/exporteren;
- Help/theme.

Bovenin staat duidelijk: 🔒 Vergrendeld.

UNDO
Nieuwe Undo-knop links.

- bewaart maximaal 50 recente editorstappen;
- verwijderde nodes + paths kunnen terug;
- nodeverplaatsingen kunnen terug;
- tekst/metadata/logica/variabelen kunnen terug;
- Ctrl+Z / Cmd+Z werkt op het canvas;
- in input/textarea blijft Ctrl+Z gewoon lokale tekst-undo.

Undo is uitgeschakeld zolang Editor Lock actief is.

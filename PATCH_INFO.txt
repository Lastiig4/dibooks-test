DIBOOKS VERHAALCONTROLE V1

Knop: Structuur > Controleer mijn verhaal, onder Flags & variabelen.
Geel/oranje knop; native responsive dialoog met focusbegrenzing, Escape en Sluiten.
Na de eerste controle toont Structuur het actuele aantal meldingen of een vinkje.
Resultaten werken direct bij na veranderingen; geen verouderde uitslag.

Controleert: geldige start; bereikbaarheid vanaf start; ontbrekende path-bestemmingen; keuzes inclusief Choice99; beide condition- en minigameroutes; ontbrekende afbeeldingen/video's; mogelijke onbedoelde eindes.
Kladblokken tellen niet mee. Lussen zijn toegestaan.
Ga naar node centreert het canvas en opent de node-instellingen.
Bewust einde wordt als node.data.intentionalEnd in projectdata opgeslagen, inclusief bestaande autosave/export/Undo. Deze markering verandert de Reader niet. Opheffen kan in het controlevenster. Editor Lock voorkomt wijzigingen.

Beperkingen: geen online mediabereikbaarheidscontrole, geen controle van alle inhoud of variabelewaarden, voorwaarden worden niet gesimuleerd. Bereikbaar betekent dat een structurele route bestaat. Dit is geen publicatieblokkade en geen garantie dat elk speelscenario werkt.

Installatie: backup maken, daarna bestanden uit deze ZIP op dezelfde relatieve paden in de projectroot kopieren. Bevat volledige bestanden en is cumulatief met Library/Editor V3 en Node Settings V2. Vergelijk eventuele eigen latere wijzigingen voor overschrijven.
Geen SQL of nieuwe dependencies.

Validatie: npx tsc --noEmit geslaagd; node --test lib/storyCheck.test.mjs: 6 tests geslaagd; npm run build geslaagd. Bestaande middleware-deprecatiewaarschuwing. Geen interactieve browsertest uitgevoerd.
Tests vereisen Node met TypeScript type stripping (getest op Node 24).

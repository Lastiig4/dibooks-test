DiBooks Patch - Editor Tab Focus Stability V1
==============================================

BUG
Wanneer de Auteur Studio open stond en je naar een ander browsertabblad ging,
kon bij terugkeren de auth kort refreshen.

De editor luisterde naar het HELE user-object.
Een Supabase token/profile refresh kan voor dezelfde gebruiker een nieuw
JavaScript user-object opleveren.

Gevolg:
- editor dacht dat accountcontext veranderd was;
- Dashboardboek werd opnieuw geladen;
- autosave-scope kon kort naar guest springen;
- actieve canvas kon blanco / teruggezet lijken.

FIX 1 - AUTH STABIEL BIJ TAB FOCUS
lib/auth.ts:
- alleen een echte Supabase SIGNED_OUT logt de UI direct uit;
- INITIAL_SESSION zonder session blijft correct een gast;
- tijdelijke lege sessie bij tab/browser resume wordt genegeerd;
- bij dezelfde user-ID blijven de verrijkte DB role + plan behouden tijdens
  TOKEN_REFRESHED/session refresh.

De bestaande snelle INITIAL_SESSION architectuur blijft intact.
Er is GEEN getSession()+listener race opnieuw geïntroduceerd.

FIX 2 - EDITOR RELOADT NIET OP USER OBJECT REFRESH
app/editor/page.tsx:
- load effect hangt niet meer van heel `user` af;
- alleen stabiele velden:
  authLoading + user.id + role;
- editor onthoudt welke combinatie user/role/route al geladen is;
- dezelfde scope wordt niet nogmaals over het actieve canvas geladen.

FIX 3 - KOUDE AUTH BOOT
Bij een echte browser-refresh wacht een Dashboardboek eerst totdat Supabase
INITIAL_SESSION klaar is.

Daardoor wordt een Dashboardboek niet eerst één render als guest geladen.

FIX 4 - DASHBOARD ROUTE + GEEN USER
Als een echte login ontbreekt op `/editor?book=...`, wordt niet langer een
guest-autosave over die Dashboardroute geladen.

De editor wacht op login/context in plaats van de actieve projectstate te
vervangen.

2. Sleep `app` en `lib` over `dibooks_author_studio`.
3. Bestanden vervangen.
4. npm run build.
5. Commit/push naar Vercel.

TEST
1. Open een bestaand Dashboardboek in Studio.
2. Wijzig tekst of plaats een node.
3. Wacht 1-2 sec zodat sessiesave geschreven is.
4. Ga 20-60 sec naar een ander browser-tabblad.
5. Ga terug.
6. Canvas moet EXACT blijven staan.
7. Herhaal een paar keer.
8. Laat tab eventueel 5+ minuten op achtergrond staan en test opnieuw.
9. Controleer daarna expliciet uitloggen: dat moet nog steeds echt uitloggen.

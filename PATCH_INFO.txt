DiBooks Patch - Editor Tab Focus Stability V1.1
================================================

Deze patch is een vervolg op V1.

WAT DE SCREENSHOT LIET ZIEN
Het canvas bleef inmiddels staan, maar bij terugkeer naar een browser-tab
verscheen nog kort:

'Een actief Auteur-plan is nodig...'

Dat betekende dat Supabase tijdens tab-focus nog heel kort een
SIGNED_OUT / entitlement-refresh kon afvuren.

FIX 1
Onverwachte SIGNED_OUT krijgt nu 1,8 seconde grace.

Komt binnen die tijd dezelfde geldige sessie terug:
- SIGNED_OUT wordt volledig genegeerd;
- gebruiker blijft visueel ingelogd;
- role/plan blijven stabiel;
- editor ziet geen tijdelijke downgrade.

Klik je zelf expliciet op Uitloggen:
- logout blijft direct;
- geen grace;
- normale beveiliging blijft intact.

FIX 2
De Editor bepaalt zijn geladen projectscope nu uitsluitend op:

user-id + editor-route

NIET meer op:
role / plan / compleet user-object.

Dus:
Author -> tijdelijke Reader -> Author
of
Author Pro -> tijdelijke free -> Author Pro

kan NOOIT meer het actieve canvas opnieuw laden.

FIX 3
De melding 'Author Pro nodig' wordt alleen nog gebruikt bij de echte eerste
poging om een Dashboardboek zonder rechten te openen.

Een reeds geladen project reageert niet op tijdelijke entitlement-refreshes.

BELANGRIJK
Save/publish beveiliging blijft bestaan.
Als een abonnement echt is beëindigd, worden server-side/auteur-permissions
bij opslaan/publiceren nog steeds afgedwongen.

GEEN SQL NODIG.

INSTALLEREN
1. ZIP uitpakken.
2. `app` en `lib` vervangen.
3. npm run build.
4. Push/deploy.
5. Zelfde tab-wisseltest opnieuw uitvoeren.

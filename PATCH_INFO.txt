DiBooks Patch - Editor UI Categories V1.1
=======================================

Kleine UI-aanpassing bovenop V1.

Wijzigingen:
- Keuzemenu is verplaatst van 'Tekst & schrijven' naar 'Media & interactie'.
- Hele boek previewen is verwijderd uit het Project-flyoutmenu.
- De groene Play-knop staat weer los als vaste knop op de linker toolbar.
- Project bevat nu alleen:
  - Opslaan / exporteren
  - Project laden

Geen SQL nodig.
Geen andere Editor-functionaliteit aangepast.

Installeren:
1. ZIP uitpakken.
2. Sleep de map 'app' over dibooks_author_studio.
3. Kies Bestanden vervangen.
4. npm run build
5. Commit/push.

DiBooks Patch - Dropdown Theme + Start Chapter V1
================================================

Dit is een gecombineerde patch.

1. READER DROPDOWN THEME FIX
Bevat de vorige fix die je nog niet had toegepast:
- Donker thema -> native dropdowns openen donker.
- Oud boek -> native dropdowns openen donker.
- Licht thema -> native dropdowns openen licht.

2. NIEUW SCHOON PROJECT START MET HOOFDSTUK-MARKER
Voorheen:
- node_1 = normale tekstnode "Intro"

Voortaan:
- node_1 = Hoofdstuk-marker
- label = Hoofdstuk 1
- chapterNumber = 1
- deze node is automatisch de start-node

Nieuwe workflow:
Hoofdstuk 1 -> eerste tekstnode -> ...

Reset editor gebruikt dezelfde initialNodes en begint dus ook opnieuw
met Hoofdstuk 1 in plaats van een lege normale tekstpagina.

De hoofdstuk-marker:
- telt niet mee als verhaalnode;
- verschijnt niet als eigen readerpagina;
- is alleen structuur;
- gebruikt één vervolgpath.

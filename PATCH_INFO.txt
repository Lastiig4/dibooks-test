DiBooks Patch - Reader Readback History V1
=========================================

BELANGRIJK:
RUN EERST:
READER_READBACK_HISTORY_V1_SUPABASE.sql
in Supabase SQL Editor.

WAT DEZE PATCH DOET

1. Leesgeschiedenis per verhaalrun
De Reader bewaart voortaan het werkelijk gevolgde pad in
reading_progress.run_history.

Opgeslagen wordt o.a.:
- welke scene/node bereikt is;
- via welk pad iemand doorging;
- gekozen keuze-optie;
- success/fail van minigame;
- TRUE/ELSE route van IF;
- Function- en hoofdstuk-overgangen.

2. Teruglezen zonder verhaal te veranderen
Als de lezer teruggaat voorbij de eerste pagina van de huidige scene,
schakelt DiBooks naar TERUGLEESMODUS.

In die modus:
- story state verandert NIET;
- Function nodes worden NIET opnieuw uitgevoerd;
- IF nodes worden NIET opnieuw berekend;
- keuzes kunnen NIET gewijzigd worden;
- de eerder gekozen optie is gemarkeerd als 'Jouw keuze';
- minigames worden NIET opnieuw gespeeld;
- het oude success/fail resultaat wordt getoond;
- echte leesvoortgang blijft op de oorspronkelijke positie.

Bovenin staat:
'Terugleesmodus'
+ knop 'Terug naar waar ik was'.

3. Interactieve grenzen blokkeren teruglezen niet meer
Je kunt nu terug over:
- tekst;
- keuzes;
- minigames;
- cutscenes;
- hoofdstukovergangen;
- Function/IF nodes (deze worden intern overgeslagen).

Dus een keuzemenu of minigame is niet meer het verste punt waar je
naar terug kunt.

4. Inhoud / hoofdstukken
Nieuwe knop 'Inhoud' in Reader header.

Toont ALLEEN hoofdstukken die in deze specifieke verhaalrun werkelijk
zijn bereikt.

Geen toekomstige hoofdstukken.
Geen alternatieve niet-gekozen hoofdstukken.
Dus geen spoilers en geen mogelijkheid om vooruit te springen.

Klik op een bereikt hoofdstuk:
-> opent dat hoofdstuk in read-only terugleesmodus.

5. Normale vorige knop
Op pagina > 1:
'Vorige pagina'

Op pagina 1, wanneer er een eerder bezocht onderdeel bestaat:
'Teruglezen'

Daarmee stap je logisch door je echte eerdere route heen.

6. Opnieuw lezen
'Opnieuw lezen' wist zoals voorheen reading_progress.
Daarmee wordt ook run_history gewist en begint een volledig nieuwe run.
Dat is de enige manier om bewust een ander interactief pad te spelen.

LET OP BESTAANDE LEESRUNS
Oude leesruns hebben vóór deze patch nog geen routegeschiedenis.
Bij eerste openen wordt daarom het huidige punt als start van de nieuwe
geschiedenis gebruikt.

Voor een volledige terugleesgeschiedenis vanaf het begin:
druk één keer op 'Opnieuw lezen' en lees daarna verder.
Nieuwe runs worden volledig bijgehouden.

INSTALLEREN
1. ZIP uitpakken.
2. RUN EERST READER_READBACK_HISTORY_V1_SUPABASE.sql in Supabase.
3. Sleep daarna map 'app' over dibooks_author_studio.
4. Bestanden vervangen.
5. npm run build
6. Commit/push naar GitHub/Vercel.

TEST
1. Start boek opnieuw.
2. Lees tekst -> maak keuze -> speel minigame -> lees verder.
3. Ga op pagina 1 terug via 'Teruglezen'.
4. Controleer dat keuze zichtbaar maar geblokkeerd is.
5. Controleer dat minigame alleen resultaat toont.
6. Klik 'Terug naar waar ik was'.
7. Controleer dat je weer exact op je echte voortgang staat.
8. Open 'Inhoud' en controleer dat alleen bereikte hoofdstukken zichtbaar zijn.

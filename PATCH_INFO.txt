DiBooks Patch - Account Contacts Chat Cleanup V1
================================================

DOEL
Account en Chat rustiger maken zonder de bestaande Supabase sociale backend
te vervangen.

ACCOUNT

1. Grote drukte verminderd
- Grote marketing/introkaart vervangen door compacte Account-header.
- Profielkaart blijft bestaan.
- Rol en plan blijven zichtbaar.
- Auteur Dashboard / Studio blijft bereikbaar.

2. Verder lezen verwijderd
De Account-pagina haalt geen reading_progress-lijst meer op en toont geen
aparte 'Verder lezen'-kaarten meer.

Favorieten blijven wel zichtbaar en linken naar /favorites.

3. Vrienden veel duidelijker
Eén centrale Vrienden-kaart:

Vriend toevoegen
[ Naam of e-mailadres                     ] [ Zoek ]

Daaronder alleen wanneer relevant:
- zoekresultaten;
- inkomende vriendschapsverzoeken;
- Mijn vrienden;
- verstuurde verzoeken, compact ingeklapt.

Iedere geaccepteerde vriend heeft direct:
[ Chat ]

Deze opent:
/chat?contact=<user id>

4. Delen / feedback blijft behouden
De bestaande sociale auteurfuncties blijven:
- gedeelde boeken;
- ontvangen feedback;
- bewerkingsvoorstellen;
- voorstellen accepteren/afwijzen.

CHAT

5. Contacten zijn nu de hoofdsidebar
De oude aparte 'Inbox' + 'Nieuwe chat'-blokken zijn samengevoegd.

Links staat:
- Vriend toevoegen;
- Mijn vrienden;
- laatste bericht wanneer er al een gesprek bestaat.

Klik op een vriend:
- bestaand gesprek opent;
- of DiBooks maakt automatisch het eerste directe gesprek aan.

6. Mensen toevoegen vanuit Chat
Chat gebruikt dezelfde bestaande Supabase functies als Account:
- zoeken op naam/e-mail;
- vriendschapsverzoek sturen.

Een verstuurd verzoek verschijnt pas als vriend nadat de andere gebruiker
het heeft geaccepteerd.

7. Deeplink Account -> Chat
Klik je bij een vriend in Account op Chat, dan opent Chat die persoon direct.
Bestaat er nog geen gesprek, dan wordt het gesprek aangemaakt.

NIET AANGEPAST
- Supabase tabellen / RPC's;
- auth;
- rollen/plannen;
- boekdelen;
- feedback/revisions;
- moderatie;
- Reader;
- Auteur Dashboard.

GEEN SQL NODIG.

INSTALLEREN
1. ZIP uitpakken.
2. Sleep map `app` over `dibooks_author_studio`.
3. Bestanden vervangen.
4. `npm run build`.
5. Commit/push naar GitHub/Vercel.

TEST
1. Account openen.
2. Controleren dat 'Verder lezen' weg is.
3. Vriend zoeken en verzoek sturen.
4. Inkomend verzoek met ander testaccount accepteren.
5. Klik bij vriend op 'Chat'.
6. Controleer dat juiste gesprek direct opent.
7. In Chat iemand zoeken en een nieuw verzoek sturen.
8. Bestaande chatberichten versturen/controleren.

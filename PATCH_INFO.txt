DiBooks Patch - Moderation Alert Navigator V2
============================================

GEBRUIK DEZE V2 IN PLAATS VAN DE EERDERE NAVIGATOR-PATCH.

Wat de admin in de revieweditor krijgt:

ROOD - Ernstige meldingen
- Staan altijd bovenaan.
- Klik erop: DiBooks centreert meteen op de betreffende node en selecteert hem.
- In het rechter inspectiepaneel staat de volledige reden.
- Een rode/high melding mag door de admin worden toegestaan, maar ALLEEN
  met een verplichte korte motivatie. Die motivatie wordt opgeslagen.

ORANJE - Overige waarschuwingen
- Staan in een tweede rij.
- Klik erop: springt eveneens direct naar de node.
- Admin moet expliciet klikken op 'Beoordeeld & akkoord'.

Afgehandeld:
- De melding wordt groen: '✓ Akkoord'.
- Status wordt persistent opgeslagen in Supabase.
- Refresh / andere admin behoudt dus de reviewstatus.
- Teller toont bijvoorbeeld 5/8 afgehandeld.
- 'Volgende open melding' springt naar de eerstvolgende unresolved flag.

Boek goedkeuren:
- 'Goedkeuren & publiceren' blijft vergrendeld zolang er minimaal één
  waarschuwing openstaat.
- Dit wordt OOK database-side gecontroleerd; de frontend kan dit niet omzeilen.
- Afwijzen mag altijd direct en vereist feedback zoals eerder.

INSTALLATIE

1. Supabase -> SQL Editor -> New query.
2. Plak ALLES uit MODERATION_FLAG_RESOLUTION_SUPABASE.sql.
3. Klik Run.

4. Pak de ZIP uit.
5. Sleep over dibooks_author_studio:
   - app
   - lib
   - supabase
6. Kies Bestanden vervangen.

7. Test:
   npm run build

8. Commit/push.

Geen wijziging nodig aan DEEPSEEK_API_KEY.

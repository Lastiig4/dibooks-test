DiBooks Patch - AI Node Moderation
===================================

DIT BOUWT VERDER OP MODERATION CORE v1.

FLOW

Auteur:
  Indienen voor beoordeling
      ↓
  immutable review snapshot
      ↓
  automatische OpenAI moderation scan
      ↓
  verdachte nodes krijgen moderation_flags
      ↓
Admin:
  Meldingen -> Boekmoderatie
      ↓
  Open in reviewmodus
      ↓
  ⚠ verschijnt boven gemarkeerde nodes
      ↓
  Admin beslist ZELF goedkeuren / afwijzen

BELANGRIJK
De AI wijst NOOIT zelfstandig een boek af.
Flags zijn alleen signalen voor menselijke controle.

WAT WORDT GESCAND
- Tekstnodes
- Speciale tekstpagina's
- Keuzeteksten
- Titels / lezerscontent van overige relevante nodes

Utility-nodes zoals Function, IF/Condition en Kladblok worden overgeslagen.

Categorieën kunnen o.a. zijn:
- geweld / grafisch geweld
- seksuele inhoud
- seksuele inhoud met minderjarigen
- haat / bedreigende haat
- intimidatie
- zelfbeschadiging
- illegale of gevaarlijke instructies

INSTALLATIE

1. Supabase -> SQL Editor.
2. Voer AI_NODE_MODERATION_SUPABASE.sql uit.

3. Pak deze ZIP uit.
4. Sleep 'app', 'lib' en 'supabase' over dibooks_author_studio.
5. Kies Bestanden vervangen.

6. Voeg SERVER-SIDE deze environment variable toe:

   OPENAI_API_KEY=...

   BELANGRIJK:
   - NOOIT NEXT_PUBLIC_OPENAI_API_KEY gebruiken.
   - De sleutel hoort nooit in frontendcode.
   - Plak je API key niet in chat.

Lokaal:
  zet OPENAI_API_KEY in .env.local

Vercel:
  Project -> Settings -> Environment Variables
  Name: OPENAI_API_KEY
  Value: jouw project API key
  Daarna opnieuw deployen.

7. Test:
   npm run build

8. Commit/push.

TESTFLOW

A. Maak een klein testboek met bijvoorbeeld:
   - één normale onschuldige tekstnode
   - één duidelijk gewelddadige testpassage

B. Dien het boek in voor beoordeling.

C. Wacht enkele seconden en open als admin:
   Instellingen -> Boekmoderatie.

D. Gebruik eventueel:
   '✨ AI opnieuw scannen'

E. Open daarna de reviewmodus.
   Gemarkeerde nodes moeten een ⚠ tonen.

FAIL-SAFE
Als OPENAI_API_KEY ontbreekt of OpenAI tijdelijk niet bereikbaar is:
- het boek blijft gewoon 'In afwachting';
- de menselijke reviewflow blijft werken;
- de admin kan later opnieuw scannen.

De scanner gebruikt OpenAI omni-moderation-latest.

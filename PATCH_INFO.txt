DiBooks Patch - Choice99 TS Fix V1.1
====================================

VERCEL ERROR
app/editor/page.tsx:7043

Property 'effects' does not exist on type:
{ label: string; targetNodeId?: string; effects?: FunctionAction[] }
|
{ label: string; targetNodeId: string }

OORZAAK
De nieuwe 3 standaardkeuzes van Choice99 werden door TypeScript automatisch
geïnferreerd als een simpeler objecttype zonder `effects`.

Wanneer de editor vervolgens deed:

choice.effects ?? []

zag TypeScript een union waarvan één variant geen `effects` had.

FIX
Er is nu één expliciet type:

ChoiceOption

met:
- label
- targetNodeId
- effects

Alle plekken gebruiken nu exact hetzelfde type:
- opgeslagen keuzes
- de 3 standaardkeuzes
- nieuwe keuze toevoegen
- fallback bij updateSelectedChoice

De standaardkeuzes starten ook expliciet met:
effects: []

BEHOUDEN
- minimaal 3 keuzes
- maximaal 99 keuzes
- + Keuze toevoegen
- keuzes verwijderen vanaf keuze 4
- A/B/C ... Z/AA/AB labels
- Variable Effects
- Reader Feedback
- Tutorials-systeem
- Afbeelding-node
- Editor Lock / Undo
- Scene Info

GEEN SQL NODIG VOOR DEZE FIX.
Als je de SQL uit de vorige Tutorials + Choice99 patch nog niet had uitgevoerd,
moet die natuurlijk nog wel eenmalig uitgevoerd worden.
